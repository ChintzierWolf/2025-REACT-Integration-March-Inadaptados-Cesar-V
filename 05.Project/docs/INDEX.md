## 🛠️ Stack Tecnológico Canónico

### Backend (`/ecommerce-api`)
- **Runtime**: Node.js (v20+)
- **Framework**: Express.js
- **Base de Datos**: MongoDB (Mongoose)
- **Seguridad**: JWT, Helmet, Rate Limit, Bcrypt
- **Testing**: Vitest, Supertest
- **Docs**: Swagger JSDoc

### Frontend (`/ecommerce-app`)
- **Framework**: React 18+ (Vite)
- **Estado**: Zustand (Global), React Query (Server)
- **Estilos**: Vanilla CSS (Atomic Design)
- **Testing**: Cypress (E2E)
