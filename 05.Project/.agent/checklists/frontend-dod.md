# Checklist: Definition of Done (DoD) - Frontend

Antes de entregar una unidad de trabajo de frontend, el subagente debe verificar:

## Código y Calidad
- [ ] El código sigue las guías de estilo del proyecto.
- [ ] No hay console.logs de debug o código comentado.
- [ ] Se han usado componentes del sistema de diseño (Atomic Design).
- [ ] Las props están validadas (PropTypes/TypeScript).

## UI/UX
- [ ] El componente es responsivo en móviles, tablets y desktop.
- [ ] El manejo de estados (Loading, Empty, Error) está implementado.
- [ ] Los assets (imágenes/iconos) están optimizados.

## Tests y Verificación
- [ ] Los tests unitarios pasan al 100%.
- [ ] Se ha verificado la accesibilidad básica (Aria, contrastes).
- [ ] Funciona correctamente en los navegadores definidos.

## Documentación
- [ ] El Spec ha sido actualizado con los resultados.
- [ ] Los nuevos componentes están documentados si es necesario.
