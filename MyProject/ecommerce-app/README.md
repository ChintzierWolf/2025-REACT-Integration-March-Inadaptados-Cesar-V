# GamezVazStore

Bienvenido a **GamezVazStore**, tu tienda en línea especializada en videojuegos, consolas y accesorios para Xbox y Nintendo.

## Descripción

Este proyecto es una maqueta funcional de un e-commerce desarrollada en React. Incluye:

- Catálogo de productos (Consolas, Videojuegos, Accesorios).
- Carrito de compras persistente.
- Flujo de compra completo (Checkout simulado).
- Diseño moderno inspirado en la estética Gamer/Xbox.

## Instalación y Ejecución

1.  Asegúrate de tener Node.js instalado.
2.  Navega a la carpeta del proyecto:
    ```bash
    cd project-app
    ```
3.  Instala las dependencias:
    ```bash
    npm install
    ```
4.  Inicia el servidor de desarrollo:
    ```bash
    npm start
    ```
5.  Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Tecnologías

- **React** (Create React App)
- **React Router** (Navegación)
- **Context API** (Estado global del carrito)
- **CSS Modules / Variables** (Estilos personalizados)

## Estructura del Proyecto

- `src/components`: Componentes reutilizables (Botones, Tarjetas, etc.).
- `src/pages`: Vistas principales (Home, Cart, Checkout, etc.).
- `src/context`: Lógica de estado global.
- `src/data`: Datos simulados (productos, categorías).
